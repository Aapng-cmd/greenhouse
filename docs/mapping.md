# МАППИНГ. ВЫЧИСЛИТЕЛЬНЫЙ КОНТУР ТЕПЛИЦЫ

Вариант 22: ИБ ИЗ2 ПЗ1 Д1ОЗ2 Д1ОО4 Д2П2 Д2Б4 ОР1 ОД1

| Элемент СМО | Сущность бизнес-домена | Назначение |
|---|---|---|
| Источник (ИБ) | Датчик контура теплицы: И1 температура, И2 влажность, И3 свет, И4 вредители | Формирует бесконечный поток заявок на расчёт. После очередного съёма источник сразу планирует следующий. |
| Закон генерации (ИЗ2) | Джиттер опроса датчика | Интервалы между съёмами распределены равномерно в окне U[a, b]. |
| Заявка | Задание на расчёт по одному показанию | Единица работы воркера: проверка диапазона, расчёт воздействия, запись в журнал. Содержит источник, номер съёма и время поступления. Не капля воды и не градус. |
| Буферная память (Д1ОЗ2) | Общая ограниченная очередь расчёта на edge-узле | Хранит заявки, которые нельзя сразу отдать воркеру. Новая заявка встаёт в хвост; при изъятии очередь сдвигается. |
| Прибор (ПЗ1) | Worker-процесс группы показателя (P1-P2 температура, P3-P4 влажность, P5-P6 свет, P7-P8 вредители) | Считает одну заявку своего контура. Время расчёта - экспоненциальное. Нагреватель, лампа и распылитель приборами СМО не являются. |
| Диспетчер постановки | Алгоритм приёма съёмов в очередь | Срабатывает при появлении новой заявки. Ставит её только в буфер. Приборов не знает. |
| Дисциплина отказа (Д1ОО4) | Вытеснение самого свежего съёма | При полной очереди удаляется заявка, поступившая последней (меньше всех ждала). На её место встаёт новая. Отказ фиксируется в статистике. |
| Диспетчер выбора | Алгоритм назначения расчёта | Срабатывает, когда в очереди есть заявка и свободен воркер её группы. Берёт одну заявку и назначает прибор группы. |
| Выбор заявки (Д2Б4) | Приоритет контура, по одной заявке | Сначала контур с меньшим номером источника (И1 важнее И4), среди равных - самая старая заявка. Пакет не формируется. |
| Выбор прибора (Д2П2) | Кольцо внутри группы показателя | Поиск свободного воркера начинается с указателя группы и идёт по кругу. После назначения указатель сдвигается. |
| Отказ | Съём, не дошедший до расчёта | Заявка покидает систему без команды актуатору. Возможен только в буфере: воркеры не ломаются, они свободны или заняты. |
| Обслуживание | Расчёт на воркере | Worker выполняет заявку; по завершении климат сдвигается к оптимуму контура (нагрев/охлаждение, полив/вентиляция, UV/зонты, химикаты). |
| Выход из системы | Завершённый или отклонённый расчёт | Заявка уходит после обслуживания либо после отказа Д1ОО4. |
| Отображение результатов (ОР1) | Сводные таблицы контуров | Число заявок, p отказа, времена ожидания и обслуживания, загрузка воркеров. |
| Отображение динамики (ОД1) | Календарь особых событий и окно теплицы | Пошагово: событие, буфер, приборы, указатель, выбранная заявка. Qt показывает среду, но не очередь. |
