# Окно теплицы: что нарисовано на картинке

Qt рисует теплицу примитивами (круги, дуги, прямоугольники). Ниже - соответствие
фигур и смысла. Полная легенда сокращений СМО остаётся в правой колонке окна.

Исходники окна разнесены по файлам:

| Файл | Что внутри |
|---|---|
| `main.cpp` | точка входа |
| `app_window.cpp` | раскладка окна, запуск `smo.py`, клавиши |
| `greenhouse_view.cpp` | анимация дома, земли, актуаторов |
| `pipeline_view.cpp` | блок-схема И / ДП / БП / ДВ / P |
| `sim_launch.cpp` | флаги CLI, совпадающие с `./smo.py step` |
| `draw_utils.cpp` | подписи, облака, вентилятор, вытяжка |

Запуск: `cd greenhouse-sim && qmake greenhouse-sim.pro && make && ./greenhouse-sim`.

Флаги совпадают с `./smo.py step` (их Qt пробрасывает в модель):

```bash
./greenhouse-sim --help
./greenhouse-sim --sources 2 --sources-temp 1 --devices 2 --devices-light 4 --buffer-dwell 0.4
```

`--sources N` и `--devices N` задают число **на каждую категорию** (температура, влажность, свет, вредители).
Точечные `--sources-light` / `--devices-temp` и т.п. важнее общего флага.
При 2+ приборах в категории каждый тип актуатора есть хотя бы раз (не бывает 5 зонтов без ламп).
Число фигур на картинке совпадает с каталогом приборов: 3 зонта + 2 лампы рисуются как три зонта и две лампы.

`--json-lines` и `--pull` всегда включены: так окно читает кадры. `--infinite` по умолчанию;
`-n 50` запускает конечный прогон.

## Небо и погода

| Что видно | Что это |
|---|---|
| Жёлтый диск с лучами справа вверху | Солнце. Яркость лучей растёт с показателем "свет" |
| Белые овалы на небе | Облака. Их число (2-4) и размер задают `cloud_cover`: чем больше облака, тем сильнее падает освещённость |
| Цифра `облака: 0.xx` в шапке | Доля закрытия неба от 0 (ясно) до ~0.8 (пасмурно) |

Облака считает модель (`ClimateState._update_clouds`). Освещение:
`свет = погода * (1 - 0.7 * cloud_cover) + UV-лампы`.

## Каркас теплицы

| Что видно | Что это |
|---|---|
| Зелёно-коричневая полоса под домом | Земля: дом стоит на грунте, не в воздухе |
| Красная двускатная крыша | Крыша теплицы |
| Полупрозрачный зелёный прямоугольник с крестом | Стекло и переплёт |
| Коричневая полоса внутри внизу | Почва грядки |
| Три зелёных стебля с листьями | Растения (выше, если влажность больше) |

## Актуаторы (приборы теплицы, не приборы СМО)

Приборы СМО - это воркеры P на схеме справа. На картинке слева - эффекторы,
которые включаются после обслуживания заявки. Каждый сначала виден "выключенным",
затем плавно переходит во "вкл". Один актуатор крутит только свою группу.

### Температура (заявки И1)

| Что видно | Где | Что это |
|---|---|---|
| Металлический корпус с вертикальными рёбрами | У стекла слева/справа внизу | Батарея. Подпись `батарея` |
| Оранжевые дуги над батареей | Там же | Жар на команде "нагрев" |
| Голубой квадратный корпус с круглыми лопастями | У левой / правой / задней стены у потолка | Вентилятор охлаждения. Подпись `вентилятор` |
| Голубые чёрточки вбок от корпуса | Там же | Поток воздуха на команде "охлаждение" |

### Влажность (заявки И2)

| Что видно | Где | Что это |
|---|---|---|
| Труба-дымоход на скате крыши, раструб и крутящаяся шапка | На крыше | Вытяжка. Не путать с настенным вентилятором: это дефлектор, пар идёт вверх. Подпись `вытяжка` |
| Кружки-лейки под потолком | Вдоль балки | Полив. Подпись `полив` |
| Синие капли вниз | Из леек | Вода на команде "полив" |

### Свет (заявки И3)

| Что видно | Где | Что это |
|---|---|---|
| Зонты: палка, крючок, купол со спицами | На крыше | Затенение. Купол раскрывается на команде "зонты". Подпись `зонты` |
| Серые планки на подвесах, внутри фиолетовая трубка | Под потолком вдоль балки | UV-лампы досветки. Подпись `UV-лампы` |
| Фиолетовое свечение вниз | Из ламп | Лампы включены (команда "UV-лампы") |

Если облака слишком затенили теплицу, модель включает UV. Если света слишком много - раскрывает зонты.

### Вредители (заявки И4)

| Что видно | Где | Что это |
|---|---|---|
| Коричневые жуки: тело, голова, усики, лапки | На растениях | Вредители. Их больше, если показатель "вредители" растёт. Подпись `вредители` |
| Зелёные баллончики | Под потолком | Распылители химикатов. Подпись `химикаты` |
| Жёлтая табличка с крестом у почвы | У грядки | Ловушки. Подпись `ловушки` |
| Салатовые овалы (не путать с белыми облаками на небе) | Из распылителей | Туман химикатов на команде "химикаты" |

Белые облака на небе режут свет. Зелёные овалы внутри теплицы - обработка от вредителей.

## Схема по центру

Два блока: "Приём в буфер" (И -> ДП -> БП) и "Выдача из буфера" (БП -> ДВ -> приборы).
Шары от ДВ летят к тем P, которые в этом кадре реально заняли заявку.

Приборы стоят колонками по категориям. Цвет колонки совпадает с датчиком.
В "Расшифровке сообщений" приборы сгруппированы по типу:

```
P1, P3 - зонты, delta = -1.20
P2 - UV-лампы, delta = +1.60
```

## Шапка слева

- `оптимум` / `сейчас` - целевые и фактические ростовые условия
- `команда` - какой актуатор сейчас в работе
- `облака` - текущая облачность, 0..1
- CO2 без перевода: общепринятое обозначение
